# Security

These plugins run inside Claude Code with your permissions: hooks and scripts execute on your machine, and agents can edit files and run commands you allow.

To report a vulnerability, such as a hook that runs untrusted input or a skill that bypasses an approval gate, use [private vulnerability reporting](https://github.com/LucasAntunesdeAlmeida/laa-claude/security/advisories/new). Don't open a public issue.
